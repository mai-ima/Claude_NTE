## フェーズ1-2: 記事機能・lib

### 直した問題

#### 🟠 自動リンクが同じ記事へ何度も張られていた

本文の用語自動リンク（`rehype-term-links.mjs`）は「1ページ・1**フレーズ**につき1回」で
数えていたため、**別名を持つ用語が同じ記事へ2〜3回リンク**されていた。

例: `/characters/shinku/` から `/terms/crit/` へ「会心率」「会心ダメージ」「会心」で**3回**。
`/terms/arc/` へ「弧盤」「武器」で2回。

- **237ページ中 97ページ（41%）** で発生していた
- 本文が青だらけになり、読みづらいうえに「別の記事へのリンク」と誤解させる

→ 「1ページ・1**宛先**につき1回」に変更。
**自動リンク 1449 → 1232 件、重複ページ 97 → 0。**

#### 🟡 aliases が1行形式でしか読めなかった

`aliases: ["a", "b"]` は読めるが、YAML の複数行形式

```yaml
aliases:
  - "a"
  - "b"
```

は**無言で無視**され、自動リンクが効かなくなる状態だった（現在の112件はすべて1行形式なので
実害は出ていなかった）。→ 両方の形式を読めるようにした。

### `checked`（最終確認日）を新設した

**問題**: 全264記事のうち184件が `updated: 2026-06` のままで、「本当に古い記事」と
「内容は正しいが日付を上げていない記事」が読者から区別できなかった。

`updated` を今日にすれば見た目は新しくなるが、**書き換えていないのに「更新した」と
言うのは誠実性ルールに反する**。かといって放置すると3ヶ月前の情報に見える。

→ **`checked`（任意）** を frontmatter に足した。

| 項目 | 意味 |
| --- | --- |
| `updated` | **本文を書き換えた**日 |
| `checked` | 本文は変えず、**出典に当たり直して現行版でも正しいと確かめた**日 |

- 記事ページでは `更新: 2026/6/11` の隣に `確認: 2026/9/6` が出る（`checked > updated` のときのみ）。
- `pnpm test:content` の鮮度サマリーは**新しい方**を見る。
- `checked` が未来・`checked < updated` は検査で落ちる。

上の全項目突合をもって、NTE 側で 2026-06／07 のままだった **184件に `checked: 2026-09-06`** を付けた。
α wiki（サンプルデータ）は出典で裏を取れないので対象外。
