## フェーズ1-1: ツール（13種）

### 直した問題

#### 🔴 重大: ガチャの基礎S率が誤っていた（1.87% → 0.99%）

`GachaDashboard.tsx` / `GachaSim.tsx` / `GachaPity.tsx` の3つとも、基礎S率を **1.87%** と
していたが、正しくは **0.99%**。

- **影響**: 累積確率が実際よりかなり楽観的に出ていた。
  70連時点で **誤 73.3% / 正 50.2%**。「あと何連で引けるか」の目安が全部ズレていた
- **出典**: ゲームウィズ「ガチャの排出確率と仕様」ほかで再確認（2026-09）。
  70連以降 19.59%・天井90連・すり抜けなし・円石160＝サイコロ1 は正しかった
- **サイト内で矛盾していた**: 記事 `terms/pity.md` は正しく「約0.99% → 約19.59%」と書いており、
  **ツールだけが間違っていた**
- **直し方**: 定数を修正。`GachaPity` は端末に保存された値を使うため、
  **保存済みの 1.87 を読み出し時に 0.99 へ補正**する処理を入れた（既存利用者が古い値のままに
  ならないように）

#### 🟠 専用ページのツールにエラーバウンダリが無かった

`/tools/[id]` のツールは `ToolHost` が包んでいたが、**専用ページを持つ5つ**
（ティア表・チームビルダー・マップ・比較・カレンダー）は直接描画していたため、
中で例外が出るとページが白くなっていた。

→ `withBoundary.tsx`（HOC）を新設して両方を揃えた。`ToolHost` を専用ページで使うと
全ツールを読み込んで重くなるため、HOC にしてページごとのバンドルを増やさない形にした。

#### 🟠 死んだコードが残っていた

`GachaOdds.tsx`（141行）と `GachaBudget.tsx`（112行）は、どこからも import されていない。
`astro.config.mjs` のリダイレクトで `/tools/gacha-odds/` → `/tools/gacha-dashboard/` に
統合済みで、実装は `GachaDashboard` に移っていた。→ 削除。

#### 🟡 日本語wikiなのに英語が残っていた

`GachaPity.tsx` の表示に **「Annulith」** が2箇所（記事側は「円石」に統一済み。
v0.9.1 の英語露出の一掃で**ツール内を見落としていた**）。→「円石」に修正。

`Planner.tsx` の既定タスクに **「Beyond the Rails を進める」**。
日本版で対応する名称が確認できなかったため、実在が確認できた週課
（ウィークリーリーグ／カーペホテルのオークション／古い郵便箱の特別市内依頼）に差し替えた。

#### 🟡 Planner: 調整した設定値が保存されていなかった

上限・回復速度・1周のコスト・シティスタミナ上限が `useState` だったため、
**調整してもページを開き直すと既定値に戻っていた**。→ `useStore` に変更。

#### 🟡 Timer: カウンターが負の値になれた

周回数・素材数を数えるものなので `Math.max(0, …)` を入れた。

#### 🟡 Notes: 削除に確認が無かった

長文のメモが1タップで消え、元に戻せなかった。→ 中身があるときだけ確認する。
編集欄に `aria-label` も追加。

#### 🟡 EventTimeline: 裏に回しても毎秒更新し続けていた

`visibilitychange` で止めるようにした（電池の無駄をなくす）。

#### 🟠 属性反応のデータが2箇所にあり、表示も食い違っていた

`TeamBuilder.tsx` が Duo / Trio 反応の表を**独自に持っていた**（`nav.ts` の `DUO_REACTIONS` を
使っていなかった）。組み合わせ自体は一致していたが:

- チームビルダーは **英語名のみ**（「Blossom」「Nova」）
- 異能連環チェッカーは **日本語名**（「創生」「暗星」）

と、同じ反応が**画面によって別の名前で出ていた**。日本語wikiとして不適切。
トリオ反応にいたっては、`nav.ts` に定義が無く**2つのツールがそれぞれハードコード**していた。

→ `nav.ts` に `TRIO_REACTIONS` を新設して定義を集約し、両ツールともそれを参照するようにした。
表示は日本語名を主・英語を `title` に回して統一。
`test/nav.test.ts` に回帰テストを追加（日本語名と効果が必ずあること、
トリオは3属性でありすべて既知の属性であること）。

#### 🟡 ReactionChart: 属性リングがキーボードで操作できなかった

`<g onClick>` だけで `tabindex` も Enter/Space も無く、キーボードでは属性を選べなかった。
`<svg role="img">` にしていたため、中のボタンが支援技術から見えてもいなかった。
→ `role="button"` + `tabindex` + `aria-pressed` + キー操作を追加。`role="group"` に変更。
フォーカスが見えるよう `.rc-node:focus-visible` も追加。

#### 🟡 InteractiveMap: スクロールしようとすると削除確認が出た

ピンの長押し削除が `pointerdown` から550msで発火し、**`pointermove` を見ていなかった**ため、
指を置いたままスクロールしようとしただけで削除確認が出ていた。
→ 押し始めから10px以上動いたら取り消すようにし、`pointercancel` も拾うようにした。
ピンに `aria-label` / `aria-pressed` が無かったのも修正。

#### 🟡 TierList: 並べ替えが1タップで消えた

「初期状態にリセット」に確認が無かった。→ 変更がある時だけ確認を出し、
変更が無いときはボタンを無効化。キャラの選択状態も `aria-pressed` で伝えるようにした。

### 残した課題（今回は直していない）

- **`phaseOf` が2箇所にある**（`src/lib/content.ts` とツール側）。ツール側は
  「見ている今」で再判定する必要があり、`lib` 側は `astro:content` に依存するため
  クライアントから import できない。**意図的な重複**であることをコメントで明示した。
  片方だけ直すと一覧とタイムラインで表示がズレるので注意
- `Notes` は1文字打つたびに localStorage へ書いている。長文だと無駄が多い（debounce の余地）
- タイマー終了の知らせが通知のみ。通知を拒否していると画面を見ていないと分からない
