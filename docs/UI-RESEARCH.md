# UI-RESEARCH.md — 各ゲームのUIを観察した記録

> このサイトは wiki ごとに**そのゲームのUIを再現した独自デザイン**で作る
> （利用者の指示。`.claude/state/DECISIONS.md` 2026-09-07）。
> ここは**観察して確かめたこと**を残す台帳。次のセッションが同じ調査を繰り返さないためのもの。
>
> **推測と観察を混ぜないこと。** 確認できなかったものは「確認できず」と書く。

## 調べ方（この環境で実際に効いた手順）

```bash
# 1. 公式サイトの HTML を取る（curl はプロキシを通る）
curl -s -L --max-time 30 "<公式URL>" -o site.html

# 2. HTML から CSS の URL を拾って全部つなげる
for c in $(grep -oE 'https://[^"]*\.css' site.html | sort -u); do curl -s -L "$c"; echo; done > site.css

# 3. 実際に使われている値を数える（多い順＝主要な値）
grep -oE '#[0-9a-fA-F]{6}|#[0-9a-fA-F]{3}\b|rgba?\([0-9 ,.]+\)' site.css | tr 'A-F' 'a-f' | sort | uniq -c | sort -rn | head -20
grep -oE 'border-radius:[^;}]+' site.css | sort | uniq -c | sort -rn | head
grep -oE 'clip-path:[^;}]+'     site.css | sort | uniq -c | sort -rn | head
grep -oE 'font-family:[^;}]+'   site.css | sort | uniq -c | sort -rn | head
grep -oE 'letter-spacing:[^;}]+' site.css | sort | uniq -c | sort -rn | head
```

> ⚠ **Playwright で外部サイトは開けない**。この環境のプロキシは `curl` を通すが、
> ブラウザからの外部アクセスは `net::ERR_CONNECTION_RESET` で切られる。
> スクリーンショットによる観察は諦めて、**CSS の実測**に切り替えること。
>
> ⚠ サイトによっては CSS がリセットだけで、見た目は JS が動的に作る。
> その場合この手順では取れない（下記の鳴潮・原神・スターレイルがそれ）。

## アークナイツ：エンドフィールド — **信頼度: 高**（公式CSS 370KB を実測）

出典: <https://endfield.gryphline.com/ja-jp> が読み込む CSS 全ファイル（2026-09-07 取得）

### 配色（出現回数の多い順）

| 色 | 回数 | 役割の推定 |
| --- | --- | --- |
| `#191919` | 85 | **主背景（黒）** |
| `#fff` | 76 | 文字 |
| **`#fffa00`** | **57** | **アクセント（蛍光イエロー）** |
| `#d9d9d9` | 22 | 明るい灰（副次の文字） |
| `#999` | 19 | 中間の灰 |
| `#35373c` | 15 | 面の灰（パネル背景） |
| `#00ffa2` | 9 | 明るい緑（補助・状態表示か） |
| `#ff1aac` | 6 | マゼンタ（補助） |

> **私の事前の推測（アンバー `#f0a020`）は外れだった。**
> 実際はもっと鮮烈な**蛍光イエロー `#fffa00`**。推測で作らずに測ってよかった例。

### 形

- `border-radius` は **4px / 2px / .25rem** が中心。**角丸はごく小さい**
  （`50%` は円形ボタン用、`2.625rem` 等はピル型ボタン用）
- **`clip-path: polygon(...)` を多用**。矩形マスクのほか
  `polygon(0 20%,100% 50%,0 80%,0 80%)` のような**斜めの三角**もある
  → 直線と斜めの切り欠きが意匠の一部

### タイポグラフィ

- `Novecentosanswide-Bold / DemiBold / Medium`
  … **幅広・大文字主体のジオメトリックサンセリフ**。英字ラベルに使われている
- `Gilroy-Medium / Light`、独自の `SansMedium / SansRegular / SansBold`
- `letter-spacing` は **-.02em 〜 -.03em（詰める）** が中心。
  一部に `1rem` / `.08em` の大きく開けた指定 → **開けるのはラベル用途**

### 再現の方針（この観察に基づく）

- 背景 `#191919` / 文字 `#fff` / アクセント `#fffa00` / 面 `#35373c`
- 角丸は 2〜4px。**箱ではなく罫線で区切る**
- 見出しの英字は**幅広・大文字・字間を開ける**（フォントは同梱できないので
  `system-ui` 系＋`letter-spacing` と `font-stretch` で近づける）
- 斜めの切り欠きを `clip-path` で少量使う（多用すると読みにくくなる）
- 蛍光イエローは**面積を絞る**。黒地に大面積で置くと目に痛い

## 崩壊：スターレイル — **信頼度: 中**（UI解説記事の記述）

出典: [崩壊：スターレイルのUIをよく見てみる(1)（note / opvelll）](https://note.com/opvel/n/n2ecf011636cd)

- 配色は **黄色・黒・白の3色**構成（ランチャーのパレット）。イベントで背景が変わる
- 小型ポップアップは **右上が角丸、左下側に重なったような線**という統一処理
- **閉じるボタンは右上に統一**
- 選択要素・ターゲットに**回転するエフェクト**を当てて目立たせる
- トランジションは**方向を保つ**（下から出たら下へ消える）
- 機能を最初から全部見せず、順に開放して複雑さを緩和する設計

**確認できなかったこと**: 具体的な色コード。公式サイト（`hsr.hoyoverse.com`）は
CSS を取得できず（HTML に stylesheet のリンクが無く JS が動的に生成）。

## 原神 — **信頼度: 中**（UI解説記事の記述）

出典: [原神 デザイン考察（GameUI Lab）](https://uidesign.chodoiilife.com/genshin-things/) ／
[原神で使われているUIまとめ（note）](https://note.com/shiyoudesu/n/n4f1af4fccf17)

- アイコンは**ツートーン**（白ベタ一色ではなく、**白＋白の透明度**の2色）。
  透明度による白のグラデーションが立体感を生む
- **透過表現を加えたフラットデザイン**。オープンワールドの背景を邪魔しない
- パーティクル・影・フレア・歪みでリッチ感を足す
- **アール・デコと有機的モチーフ**を織り交ぜた装飾
- 属性ごとに色を割り当てる（例: 風＝緑）

**確認できなかったこと**: 具体的な色コード。公式サイト（`genshin.hoyoverse.com`）から
取れた CSS はキャンペーンページのもので、ゲームUIの配色ではなかった。

## 3ゲーム（原神・鳴潮・スターレイル）をどう作るか

準備中ページなので**中身は「準備中」の一言**。それでも
「そのゲームらしい画面」であることは伝えたい。そこで:

- **確認できた範囲だけを根拠にする**。色コードが取れていないものは
  「記事に書かれた特徴」（スターレイル＝黄・黒・白／原神＝透過とツートーン／
  鳴潮＝暗色のSF）を手がかりに構成し、**独自の解釈であることを承知で作る**
- 各ページに**非公式ファンサイトである旨と権利者名**を明記する
- **公式の素材（画像・ロゴ・フォント）は一切使わない**。
  形と色は CSS とインライン SVG で自作する
- あとで実物を確認できたら**この文書を更新してから**デザインを直す

> つまり、エンドフィールドは**実測に基づく再現**、
> 3ゲームは**限られた根拠に基づく解釈**。**質が違うことをここに明記しておく。**
