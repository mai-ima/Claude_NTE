# ENDFIELD-SOURCES.md — エンドフィールドの出典台帳

> 記事を書く前に**ここに出典を記録してから書く**。
> 「どこまで確かめたか」を記事の `status` と一致させるための帳簿。
>
> - **A（一次）** … 公式サイト・公式のお知らせ・公式SNS・プレスリリース
> - **B（準一次）** … 一次を引いた報道メディア（4Gamer / Game*Spark / gamebiz 等）
> - **C（二次）** … 攻略サイト・個人ブログ。**単独では `verified` にしない**
>
> `verified` にしてよいのは **A が1件**、または **B/C が2件以上一致**したとき。
> 数値（確率・天井・価格・倍率）は **A が取れるまで `draft`**（NTE でガチャ確率を
> 誤って載せた前例がある）。

最終更新: 2026-09-09

> ⚠ **公式サイト（endfield.gryphline.com）の個別ニュースはこのセッションでは取得できていない。**
> JavaScript で描画されるため `WebFetch` が本文を返さず、ニュースの id も特定できなかった。
> したがって現時点で **A（一次）は PR TIMES のプレスリリースのみ**。
> ゲーム内のお知らせに当たれる人は、そこで確かめてこの台帳を更新すること。

## 5. 調べ方のメモ

- 公式サイトは JavaScript で描画されるため、`WebFetch` では本文が取れない
  （トップも個別ニュースも同様。ニュースの id も検索から特定できなかった）。
  → **PR TIMES のプレスリリースが、現状もっとも一次に近い**。
- 報道メディア（gamebiz / 4Gamer / Game*Spark）は一次を引いているので **B** として使える。
  ただし**同じ発表から書いていても中身が食い違う**（上の「弓の練磨／弓の試練」）。
  **2件そろっても、食い違ったら断定しない。**
- 攻略サイトは**サイト間で文章が使い回されている**ことがあるため、
  「2件一致」を根拠にするときは**文が同一でないか**を見る。
