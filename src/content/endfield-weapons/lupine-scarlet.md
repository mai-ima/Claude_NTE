## 概要

**狼緋**（Lupine Scarlet）は、**★6** の**片手剣**。
入手は**購買部-武庫交換所**。

> レイジアン工業が製造する長剣の人気モデル。闇市を通じて文明地帯の外にも流通している。ランドブレーカーの間でも評判が高く、特殊な改造モジュールを追加して使う者も多い。

## 性能

左が入手した直後、右が上限まで育てたとき。

|  | **初期（基礎/上限）** | **MAX（基礎/上限）** |
| --- | --- | --- |
| **基礎攻撃力** | 51 | 505 |
| **敏捷UP・大** | 敏捷 **+20**（**1/3**） | 敏捷 **+156**（**9/9**） |
| **会心率UP・大** | 会心率**+2.5%**（**1/3**） | 会心率**+19.5%**（**9/9**） |
| **切骨・噛みつく群狼** | 攻撃力 **+16.0%** / 装備中、自身が会心ダメージを与えると狼の血を1段階獲得し、物理と灼熱ダメージ**+1.0%**（16段階まで重ね掛け可能） / 狼の血が16段階になると、20秒間物理と灼熱ダメージがさらに**+24.0%** / 持続時間が終了すると、狼の血の段階数は0になる（**1/4**） | 攻撃力 **+44.8%** / 装備中、自身が会心ダメージを与えると狼の血を1段階獲得し、物理と灼熱ダメージ**+2.8%**（16段階まで重ね掛け可能） / 狼の血が16段階になると、20秒間物理と灼熱ダメージがさらに**+67.2%** / 持続時間が終了すると、狼の血の段階数は0になる（**9/9**） |
