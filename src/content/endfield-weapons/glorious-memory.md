## 概要

**栄光の記憶**（Glorious Memory）は、**★6** の**片手剣**。
入手は**協約通行証報酬**。

> 熔炉要塞で鍛造された武器の1つ。優美で精巧な佇まいから、鉄誓軍では主に儀礼の場で用いられ、前線で使用されることはまれである。しかし剣身は幾度も磨き上げられ、その刃は比類ない鋭さを誇る。

## 性能

左が入手した直後、右が上限まで育てたとき。

|  | **初期（基礎/上限）** | **MAX（基礎/上限）** |

| **会心率UP・大** | 会心率**+2.5%**（**1/3**） | 会心率**+19.5%**（**9/9**） |
| **夜幕・消えぬ輝き** | 攻撃力**+7.0%** / 装備中、自身がスキルでクラッシュを付与すると、30秒以内に発動した次の必殺技の期間中、与えるダメージ**+12.0%** / 同名効果は3回まで重ね掛け可能 / 効果の持続時間は個別にカウントされ、0.5秒に1回まで発動可能（**1/4**） | 攻撃力**+19.6%** / 装備中、自身がスキルでクラッシュを付与すると、30秒以内に発動した次の必殺技の期間中、与えるダメージ**+33.6%** / 同名効果は3回まで重ね掛け可能 / 効果の持続時間は個別にカウントされ、0.5秒に1回まで発動可能（**9/9**） |
