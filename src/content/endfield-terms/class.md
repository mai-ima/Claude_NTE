## 概要

**職分（しょくぶん）** は、オペレーターが戦闘で担う役割の区分。
編成を組むときの目安になる。

## 6つの職分

| 職分 | 主な役割 |
| --- | --- |
| **先鋒** | 戦技ポイントの回復を担い、味方がスキルを多く使えるようにする |
| **前衛** | 前に出て攻撃を通す |
| **重装** | 打たれ強さを活かして味方を守る |
| **術師** | アーツによる攻撃を担う |
| **補助** | 味方の強化や、敵の弱体化を担う |
| **突撃** | 攻撃を仕掛けて火力を出す |

> 🛠 **要確認**: 職分の**名称**は複数の攻略サイトで一致していますが、
> **役割の説明はサイトによって表現が異なり**、「前衛」と「突撃」に同じ説明を
> 載せているサイトもありました。上の表は共通する部分だけを短く書いています。
> ゲーム内の職分説明で確かめてください。
