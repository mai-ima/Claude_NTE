## 仕組み（ボードゲーム式）

NTEのガチャは **「Scarborough Fair」** と呼ばれるボードゲーム式。**ダイス（1〜6）**を振って自分のコマ「Chuppa」をボード上で進め、止まったマスの報酬を得る。

- **リミテッドボード:** 期間限定の注目キャラ。**ソリッドダイス**を使用。
- **スタンダードボード:** 恒常。**ファブリケイテッドダイス**を使用。恒常S級は **Sakiri / Daffodill / Baicang / Jiuyuan / Fadia / Hathor**。

## 天井（ピティ）

- **ソフト天井 = 70連:** 「Board Modification」が発生し、S級排出率が**約1.87% → 約19.59%**へ跳ね上がる。
- **ハード天井 = 90連:** 注目S級が**確定**。
- **すり抜け（50/50）なし:** リミテッドボードで出たS級は**必ず注目キャラ**。
- **天井は持ち越し:** キャラ天井のカウントは失われない（化粧品系マイルストーンはバナー個別）。

> 当wikiの[ガチャ天井トラッカー](/tools/gacha-pity/)で、確定までの連数と必要 Annulith を計算できます。

## 通貨

| 通貨 | 役割 |
| --- | --- |
| **Riftcrystal** | 課金専用。Annulith に 1:1 変換。スキン等の購入に使用 |
| **Annulith** | 主要プレミアム通貨。**160 Annulith = 1 ダイス** |
| **ソリッドダイス** | リミテッドバナーの抽選 |
| **ファブリケイテッドダイス** | スタンダードバナーの抽選 |
| **Tri-Key** | 武器（Arc）バナーの抽選（10連のみ） |
| **Warp Pieces** | 重複時に得られる凸/交換通貨 |

> 基礎排出率は媒体により 0.99%〜1.87% と表記揺れがあります。最新値はゲーム内「詳細」で確認してください。
