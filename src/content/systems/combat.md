## 編成と交代

- 戦闘は **4人編成**。キャラの**交代は無償・クールタイム無し**で自由に切り替えられる（一部のエントリースキルやQTEには個別CTあり）。
- アクション主体で、通常攻撃・スキル・EXレール終結・回避・パリィを組み合わせて戦う。

## スキルの種類

1人のキャラクターは次を持つ。**発動の条件がそれぞれ違う**。

| 種類 | 何で出るか |
| --- | --- |
| **通常攻撃** | 押すだけ |
| **[バイレールスキル](/terms/bilrail/)** | **クールダウン制**。明けたら撃てる |
| **[EXレール終結](/terms/bilrail/)** | **エネルギーを消費**して放つ必殺技 |
| **サポートスキル** | **交代したとき**に出る |
| **コンビスキル** | [連環値](/terms/renkan-value/)が最大の状態で、光っているキャラへ**交代**すると出る |
| **パッシブスキル** | 常時 |
| **[シティスキル](/terms/city-skill/)** | 戦闘の外（探索・店舗など）で効く |

## 回避・パリィ

- **極限回避:** 敵の赤い予兆の瞬間に回避すると発動し、無敵（iフレーム）を得る。
- **極限反撃:** パリィの精密な成功でカウンターが出る。キャラ固有の演出を持ち、ブレイク値も削る。

## ブレイク（スタッガー）

- 敵にはHPバー下に**スタッガー（ブレイク）ゲージ**がある。攻撃・特定の攻撃種・属性反応・回避/パリィ成功で蓄積。
- 満タンで敵は**ブレイク（スタン）**し、被ダメージが大きく上昇する。**EXレール終結を叩き込む好機**。

## ダメージの種類

通常ダメージのほか、**メンタルダメージ（Nova 反応に関連）／ブレイクダメージ／付着ダメージ**といった概念がある。

> 反応の詳細は[異能連環](/systems/esper-cycle/)を参照。
