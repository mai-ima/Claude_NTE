## どんな土地か

**武陵** は [第2章](/endfield/quests/chapter-2/) の舞台です。
水が多く、坂と崖が入り組んでいます。
[四号谷地](/endfield/areas/valley-four/)で身につけた手順が、ここでは少しずつ通じません。

| 違うところ | 中身 |
| --- | --- |
| **通貨** | 現地では **武陵取引券** を使う。持ち込んだお金は使えない |
| **地形** | 高低差が激しい。監視塔を開けて地図を見えるようにするのが先 |
| **素材** | 竹や現地の鉱石など、この土地でしか採れないものがある |
| **発電** | 水が多いので水力が使える。生産を広げると電気が足りなくなる |

## 主な場所

| 場所 | 何があるか |
| --- | --- |
| **清波砦** | 水門と昇降機の仕掛けがある砦。道を自分で作って進む |
| **武陵城** | 物語の中心。店や施設がまとまっており、依頼も受けられる |
| 侵蝕された区画 | 進むには侵蝕を解く手立てが要る |

> 🛠 **要確認**: 地図・採取できるものの一覧・監視塔の位置はまだ載せていません。

## 覚えておくと楽なこと

**着いたらまず監視塔。** 地図が見えないまま歩くと、同じ場所を何度も上り下りすることになります。

**ジップラインは考えて引く。** 張れる数に限りがあります。
拠点・城・よく採る場所を先に結ぶのが無駄になりません。

**装備をこの土地のものに。** 相手の水準が上がるので、現地で作れる[装備](/endfield/gear/)に替えます。

**迷ったら黄色い塗装と照明。** 砦の中で道に迷ったときの目印になります。
