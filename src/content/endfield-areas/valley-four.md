## どんな土地か

**四号谷地** は [第1章](/endfield/quests/chapter-1/) の舞台です。
かつて人の手が入っていた谷が荒れ、施設が壊れたまま残っています。
管理人はここで仲間と合流し、**壊れたものを直しながら西へ**進みます。

このゲームの基本は、ほぼこの土地で受け取ります。

| 覚えること | どこで |
| --- | --- |
| 戦い方（ブレイク・切り替え） | 谷の入口 |
| 電気を起こす | 拠点の復旧 |
| ものを運ぶ・加工する | 橋の修復 |
| 拠点を建てて守る | 前線基地の設営 |

## 主な場所

| 場所 | 何があるか |
| --- | --- |
| 基地 | 最初の拠点。壊れた状態から立て直す |
| 採石場 | 石材が採れる。橋の修復に要る |
| **源石研究パーク** | 機械の相手が出てくる区画。仕掛けを解いて奥へ進む |
| 鉱山 | 侵蝕された区画。無限に湧く相手の元を断つ必要がある |

> 🛠 **要確認**: 地図・採取できるものの一覧・[裂け目](/endfield/systems/combat/)の位置は
> まだ載せていません。出典が取れたものから順に足していきます。

## 覚えておくと楽なこと

**電気と運搬の線は残る。** ここで引いた線は後の章でも使えます。丁寧に作ると後が楽です。

**高いところから落ちない。** 山道では落下で痛手を受けます。ジップラインがあれば安全に降りられます。

**侵蝕の区画は元を断つ。** 相手を倒し続けるより、湧き元を壊す方が早く片づきます。
