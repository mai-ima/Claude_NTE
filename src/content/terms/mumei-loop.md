**未明の環状線** は、[軌道外領域](/terms/beyond-the-rails/)を構成する環状線のうち**メインとなる高難度ステージ**。育成した戦力を試す中心的な挑戦コンテンツである。

## 詳しく

- **位置づけ**: [軌道外領域](/terms/beyond-the-rails/)の高難度コンテンツの主軸。常時解放の[ジョイント環状線](/terms/joint-loop/)より一段歯ごたえのある内容。
- **アクセス**: [軌道外領域](/terms/beyond-the-rails/)は[ミゲル区](/locations/miguel-district/)からアクセスし、[ハンターレベル](/terms/hunter-level/) 12 到達後に解放される。
- **報酬**: 円石（プレミアム通貨）の主要供給源となる。長期育成の主軸として位置づけられる。
- **関連ステージ**: 常時解放の[ジョイント環状線](/terms/joint-loop/)、定期再編成の[黎明環状線](/terms/reimei-loop/)。

## 数値・データ

| 項目 | 内容 |
| --- | --- |
| 所属 | [軌道外領域](/terms/beyond-the-rails/)（幽霊列車モチーフの高難度エンド） |
| 解放 | [ハンターレベル](/terms/hunter-level/)12・[ミゲル区](/locations/miguel-district/)からアクセス |
| 位置づけ | メイン高難度（3環状線の主軸） |
| 主な報酬 | 円石（プレミアム通貨） |
| 各ステージの敵編成・推奨ボーダー | 要確認 |

- 軌道外領域は約22 Stopで構成され、後半（6番目以降）はInbound+Outboundに分かれて重複しない2チームが必要とされる。本環状線の具体的な構成・各ステージ詳細はゲーム内で**要確認**。

## 攻略

- **弱点合わせ**: 各ステージは敵の弱点属性が明示される。指定弱点に合わせて編成し、属性[連環反応](/systems/esper-cycle/)を組み立てるのが攻略の鍵。
- **戦力要件**: 高難度ゆえに、しっかり[突破](/terms/ascension/)・[弧盤](/terms/arc/)を整えた[エスパー](/terms/esper/)が前提になりやすい。
- **2チームの想定**: 軌道外領域の後半は2チームを求められる設計のため、AoE班と単体／ボス班を別々に育てておくと詰まりにくい。各ステージの具体的な敵編成・推奨ボーダーはゲーム内で**要確認**。

## 関わり

- 3環状線のうち**メイン高難度枠**。まず常設の[ジョイント環状線](/terms/joint-loop/)で[ハニア](/characters/haniel/)などを確保し、戦力を整えてからこちらに挑むのが基本の流れ。定期再編成の[黎明環状線](/terms/reimei-loop/)とあわせて軌道外領域の到達点を構成する。
