**弧盤研究プロジェクト（弧盤研究）** は、武器である[弧盤（Arc）](/terms/arc/)を抽選する**専用ガチャ**。キャラ用の[スカボロー市場](/terms/scarborough-fair/)とは別枠で、使う通貨も抽選方式も異なる。**トリプルキーを使い、10連単位・単発不可**で引く。S確定枠でピックアップ弧盤になる確率には上限があり、外れても続く保証枠でピックアップが確定する（キャラガチャほど単純な「すり抜けなし」ではない点に注意）。

## 仕組み

- **使用通貨**は[トリプルキー](/terms/tri-key/)。キャラ用の[サイコロ](/terms/dice/)・[円石](/terms/annulith/)は使えない別系統。
- **10連単位（単発不可）** で引く。キャラガチャのような1連ずつの抽選はできない。
- **S確定枠でピックアップ弧盤になる確率には上限がある**（外れて非ピックアップのS弧盤が出ることがある）。ただし続く保証枠でピックアップ弧盤が確定するため、最終的には狙った弧盤を取り切れる。報道されている数値では **Sランクの排出率は約3%**、**60連目でSランクが確定**とされる（保証枠の詳細は**要確認**）。
- 得た弧盤は同名を重ねて**最大4凸（Rank5）**まで強化でき、**完凸＝同名4本（計5本分）** が必要（[弧盤](/terms/arc/)）。
- すでに所持している弧盤を引いた場合は、重複保護として[ワープ系（Warp Pieces）](/items/warp-pieces/)が自動付与される。

## 数値・データ

| 項目 | 内容 |
| --- | --- |
| 通貨 | トリプルキー |
| 抽選単位 | 10連（単発不可） |
| すり抜け | S確定枠でピックアップ確率に上限あり（保証枠で確定） |
| 完凸 | 同名4本＝計5本分（最大4凸／Rank5） |

- 基礎排出率・ピックアップ確率・天井（保証）連数の具体値は**要確認**（ゲーム内「詳細」優先）。
- トリプルキーの入手元・補充手段の細部も**要確認**。

## 使い方・コツ

- 通貨がキャラ用と別系統なので、**キャラ用円石を消費せずに弧盤を狙える**。トリプルキーが貯まった分だけ計画的に回す。
- まず**無凸1本の確保**を目標にし、運用感を見てから凸（追加の10連）に進むと無駄が少ない。
- 10連単位のため、端数のトリプルキーは次の機会まで温存する。

## 注意点・よくある誤解

- キャラガチャ「スカボロー市場」と**同じガチャではない**。通貨も方式も別物。
- 「単発で1本だけ引く」はできない。最低10連単位。
- 「すり抜けなし」と紹介されることがあるが、S確定枠ではピックアップ以外のS弧盤が出る場合がある。最終的に保証枠でピックアップが確定する、という意味で捉えると正確。
