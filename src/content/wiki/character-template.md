個別キャラクターの記事を作るときの**雛形**です。`src/content/wiki/` にコピーし、フロントマターの `title` をキャラ名にして書き始めてください。数値・性能はゲーム確認後に記載し、未確認のうちは「要確認」のままにします。

## 基本情報（要確認）

| 項目 | 内容 |
| --- | --- |
| レアリティ | 要確認 |
| 属性 / タイプ | 要確認 |
| 武器種 | 要確認 |
| 役割 | 要確認（DPS / サポート等） |
| 入手方法 | 要確認 |

## 性能の概要（要確認）

> 長所・短所を一般的な観点でまとめる枠。確定情報のみ事実として記載。

- 長所：**要確認**
- 短所：**要確認**

## おすすめ育成（要確認）

- スキル優先度：**要確認**
- おすすめ武器・装備：**要確認**
- 凸ごとの強化点：**要確認**

## おすすめ編成（要確認）

- 相性の良い味方：**要確認**
- 主な活躍コンテンツ：**要確認**

## 画像の入れ方

キャラ画像を載せる場合は、画像ファイルを `src/assets/` に置き、Markdownから次のように参照します（Astroが自動で最適化します）。

```md
![キャラ名](../../assets/characters/example.png)
```

<small>※ 公式素材の利用可否・権利はご自身で確認のうえ配置してください。当wikiでは画像を同梱していません。</small>
