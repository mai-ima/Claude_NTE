ゲーム全般で一般的に使われる用語をまとめます。これらは多くのタイトルで共通する**一般的な定義**です。
NTE特有の呼称・略語が判明したら、随時このページに追記してください。

## 戦闘・役割

| 用語 | 一般的な意味 |
| --- | --- |
| DPS | 1秒あたりの与ダメージ量。主火力役そのものを指すこともある。 |
| サブDPS | 補助的に火力を出す役。メインの合間や設置スキルで貢献する。 |
| サポーター | バフ・回復・シールドなどで味方を支援する役。 |
| タンク | 敵の攻撃やヘイトを引き受け、味方を守る役。 |
| ヒーラー | 味方の体力を回復する役。 |
| バフ / デバフ | 能力の強化 / 弱体化効果。 |
| ヘイト（アグロ） | 敵が攻撃対象を選ぶ際の「狙われやすさ」。 |
| クールタイム（CT/CD） | スキルを再使用できるまでの待ち時間。 |

## 育成・収集

| 用語 | 一般的な意味 |
| --- | --- |
| ガチャ | ランダムでキャラ/アイテムを入手する仕組み。 |
| 天井 | 一定回数引くと目的のものが確定する救済システム（有無はゲーム次第）。 |
| ピックアップ | 特定対象の排出確率が上がっている状態。 |
| 凸（限界突破） | 同じ対象を重ねて性能上限を解放すること。 |
| 周回 | 同じコンテンツを繰り返しプレイして素材等を集めること。 |
| スタミナ | 行動に消費する、時間で回復するリソースの総称。 |

> 上記は一般的な定義です。NTEでの正式名称・仕様（天井の有無や回数など）は、ゲーム内表記や公式情報で確認してから固有ページに記載してください。
