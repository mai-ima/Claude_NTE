### 2026-09-08 — 下層ページまで調べ直す／NTE の UIモードを作る

**利用者の原文**

> もう1回様々なページを調べて再現して
> 一応NTEもNTEのUI再現して(設定から変更可能)にして

**決定**

| 論点 | 決定 |
| --- | --- |
| 調べる範囲 | トップだけでなく**下層ページ**（キャラクター一覧など）と**配信CSSのチャンク全部**を見る |
| NTE の見た目 | **NTE 公式サイトのUIを再現したモードを追加**する。既存の見た目は消さない |
| 切り替え | **設定から変更可能**にする（設定 → 外観 → UIモード）。既定は従来UIのまま |

- 実装は UIモード `nte`（`src/styles/ui-nte.css`）。`UI_MODES` に登録すれば
  設定パネル・起動スクリプトは自動で追従する（配列を書き写さない作り）。
- 公式サイトに明るい配色が無いため、**このモードだけはテーマの明暗によらず暗い画面**になる。
  設定を黙って無視しないよう、**設定パネルの説明文にその旨を書く**。
- 公式のフォント（LINE Seed JP / bahnschrift）は**同梱しない**。
  手元にある人だけに効くよう font-family の先頭に置き、無ければ既定へ落とす。
