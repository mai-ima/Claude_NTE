## つまずきやすい所

```bash
pnpm verify        # test → 記事検査 → 型 → build → UI検査 → リンク検査
pnpm test:browser  # 実機相当（build の後。56ページ × 2端末）
```

- **`pkill` は使わない**（自分のシェルを kill して exit 144）
- **Playwright で外部サイトは開ける**（`route` で横取りして `curl` の中身を返す）
- 圧縮された1行 CSS に `grep -o` は効かない（無言で0件）。**`node` で読む**
- CSS が JS の中にあって取れないサイトは、**画面写真の画素を canvas で読む**（`docs/FINDINGS.md`）
- **UIモードで色を変えるなら `html:root[data-ui='x']`**（`html[...]` では themes.css に負ける）
- `clip-path` のグリッチは**文字の複製が要る**。属性の手書きは足し忘れるので
  `BaseLayout` 末尾の inline スクリプトで機械的に写している（`docs/FINDINGS.md`）
- **CSS のコメントに閉じ記号を含む引用を書かない**（次のルールが丸ごと消える。
  `pnpm test:ui` が検査するようにした）
- `writing-mode` の縦書きは**フォント次第で字が重なる**。数値では気づけないので
  高解像度で撮って目で見る
- wiki を足したら `check-ui.mjs` の `INDEPENDENT_BASES` と `STYLE_MARKS` に追加する
