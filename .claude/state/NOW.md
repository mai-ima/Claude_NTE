## つまずきやすい所

```bash
pnpm verify        # test → 記事検査 → 型 → build → UI検査 → リンク検査
pnpm test:browser  # 実機相当（build の後。56ページ × 2端末）
```

- **`pkill` は使わない**（自分のシェルを kill して exit 144）
- `curl` で localhost は `--noproxy '*'`
- **Playwright で外部サイトは開ける**（直アクセスは切られるが、`route` で横取りして
  `curl` の中身を返せば動く）。**旧「開けない」は誤り** → `docs/UI-RESEARCH.md` の冒頭
- 圧縮された1行 CSS に `grep -o` は効かない（無言で0件）。**`node` で読む**
- wiki を足したら `check-ui.mjs` の `INDEPENDENT_BASES` と `STYLE_MARKS` に追加する
