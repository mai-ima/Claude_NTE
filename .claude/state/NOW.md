## つまずきやすい所

```bash
pnpm verify        # test → 記事検査 → 型 → build → UI検査 → リンク検査
pnpm test:browser  # 実機相当（build の後・単独で）
```

- **`pkill` は使わない** ／ **`test:browser` 中に `build` を走らせない**
- **`pnpm build` を `grep` に繋ぐと途中で切れる**（dist が不完全になる。実際に踏んだ）
- **本番に出るのは `main` だけ**。PR を作るかは**利用者が決める**
