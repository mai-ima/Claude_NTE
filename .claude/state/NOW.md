## つまずきやすい所

```bash
pnpm verify        # test → 記事検査 → 型 → build → UI検査 → リンク検査
pnpm test:browser  # 実機相当（build の後。64ページ × 2端末 ＋ 320px 8ページ）
```

- **`pkill` は使わない** ／ **`test:browser` 中に `build` を走らせない**
- **この環境のブラウザから外部サイトへは出られない**。公式画像の見え方を撮るときは
  `context.route()` で手元のコピーに差し替える（→ `docs/CHANGELOG-INTERNAL.md` 2026-09-13）
- **UIモードで配色を変えるなら `html:root[data-ui=...]`** ／ **`.hero` は `.page-head` でもある**
- **グリッドの子に `max-width` を書いたら `width: 100%` も書く** ／ **閉じた `<details>` は幅を持つ**
- **本番に出るのは `main` だけ**。PR を作るかは**利用者が決める**（未反映 106 コミット）
