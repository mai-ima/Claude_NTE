## つまずきやすい所

```bash
pnpm verify        # test → 記事検査 → 型 → build → UI検査 → リンク検査
pnpm test:browser  # 実機相当（build の後。64ページ × 2端末）
```

- **`pkill` は使わない**（自分のシェルを kill して exit 144）
- inline スクリプトで**関数の巻き上げに頼らない**。`var` の代入は巻き上がらない
  （`/admin/` が真っ白になった。→ `docs/CHANGELOG-INTERNAL.md` 8節）
- **UIモードで色を変えるなら `html:root[data-ui='x']`**（`html[...]` では themes.css に負ける）
- **CSS のコメントに閉じ記号を含む引用を書かない**（次のルールが丸ごと消える）
- wiki を足したら `check-ui.mjs` の `INDEPENDENT_BASES` / `STYLE_MARKS` と、
  そのレイアウトへ `SiteStateGate`・`COMMON_FOOTER_LINKS` を入れる
- **grid の列は `minmax(0, 1fr)`**（`1fr` だと最小が中身になり狭い画面で横に動く）
- **`flex: none` を安易に付けない**（縮まなくなって一覧が横にあふれた）
- **表示形式を足したら設定パネルの幅も見る**（選択肢が4つで 320px を超えた）
- **`pnpm test:browser` の実行中に `pnpm build` を走らせない**（dist が消えて 404 だらけになる）
- **解析・広告・Cookie を入れるなら、入れる前に `/legal/privacy/` を直す**
