## つまずきやすい所

```bash
pnpm verify        # test → 記事検査 → 型 → build → UI検査 → リンク検査
pnpm test:browser  # 実機相当（build の後。64ページ × 2端末 ＋ 320px 8ページ）
```

- **`pkill` は使わない** ／ **`test:browser` 中に `build` を走らせない**
- **UIモードで配色を変えるなら `html:root[data-ui=...]`**（`html[...]` では負ける）
- **`.hero` は `.page-head` でもある**（→ `docs/RECIPES.md`「9.」）
- **グリッドの子に `max-width` を書いたら `width: 100%` も書く**（stretch が切れる。2回踏んだ）
- **閉じた `<details>` の中身は幅を持つ**（`:not([open])` で `display: none` にする）
- **本番に出るのは `main` だけ**。PR を作るかは**利用者が決める**（未反映 103 コミット）
