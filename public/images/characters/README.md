# キャラクターの画像を置く場所

ここに置いた画像は、**見た目（UIモード）を「Base」にしていて、
管理ページで画像を有効にしている端末**でだけ表示されます。
ほかの見た目では、これまでどおり色と頭文字で作った図形のままです。

## 置き方

記事のIDと同じ名前にします。

```
public/images/characters/zanko.webp   → 残虹（ざんこう）のカードに出る
public/images/characters/hotori.webp  → ほとりのカードに出る
```

拡張子は `webp` / `avif` / `png` / `jpg` / `jpeg` に対応しています
（この順で探して、最初に見つかったものを使います）。

**置いていないキャラは、これまでどおりの図形のまま**です。
ビルド時にファイルの有無を確かめているので、置かなくても読み込みエラーは出ません。

## 大きさの目安

- 一覧のタイル … 正方形に切り出して表示します
- 記事の上部 … 縦長（3:4）に切り出して表示します

どちらも**上を基準に切る**ので、人物なら顔が残ります。

## 権利について

ゲームの画像・イラストの権利は各運営元にあります。
掲載する場合は、権利者が示している案内（二次利用のガイドライン等）を
ご確認のうえ、その範囲で使用してください。

なお、このフォルダの中身は Git の管理から外してあります
（`.gitignore`）。各自の端末に置いたものが、そのまま公開されることはありません。
